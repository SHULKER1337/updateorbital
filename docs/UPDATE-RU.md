# Orbital Laser — обновлённая нативная версия

Основа — Orbital Laser 0.5.9 автора Stink-O. Исходники нативной версии взяты из
официального `orbital.hnmod` релиза v0.5.9; они находятся в `native/`.
Лицензия MIT и авторство сохранены. Версия этого обновления — 0.5.10.

Целевая игра: Minecraft Java 26.3 в Horizon Nightly от 5 ноября 2026 года,
коммит `66f3981f522b24c250b21523a70080965b940424`.
Номер лаунчера и версия игры — разные вещи. Релиз Horizon v0.2.97 с пометкой
Latest устарел: сам проект рекомендует Nightly.

## Получить установочный файл

Из корня репозитория, с Python 3.11 или новее:

```powershell
python tools/build_native.py
```

Результат — `dist/orbital.hnmod` и файл с контрольной суммой SHA-256.
Это архив исходников, текстур и звуков; компиляцию игрового клиента выполняет лаунчер.
Java/Fabric/Forge этот формат не поддерживают.

## Установка

1. Закройте игру. В Horizon Launcher откройте папку отдельного тестового инстанса.
2. Поместите `orbital.hnmod` в `horizon-native-mods/`. Если там уже есть старая
   версия Orbital Laser, замените её; одновременно оставлять две версии не нужно.
3. В разделе модов выполните нативную сборку. Мод привязан к указанной Nightly;
   другие нативные моды могут требовать другую ревизию и конфликтовать с ней.
4. Запустите новый творческий мир. Команда `/orbital give` выдаёт целеуказатель.
   Клавиша R с ним в руке открывает выбор удара.
5. Для первого визуального теста выполните `/orbital terrain off`.

Удары с включённым разрушением необратимо меняют мир. Проверяйте их только
в тестовом мире, сохранив резервную копию. Файлы Minecraft в мод не включены:
игровые ресурсы готовит Horizon из вашей копии игры.

## Проверки для разработчика

```powershell
cargo test --release --manifest-path native/mixins/orbital/engine/Cargo.toml -- --test-threads=2
cargo build --manifest-path tools/wgslcheck/Cargo.toml --locked
python tools/check_native_shaders.py
python tools/test_native_package.py
```

Для проверки интеграции нужны исходники Horizon на указанном коммите и
`horizon-mixins` на `5a64af938ec86b00d53d16a408aabc0038fb3e57`.
Примените `native/mixins` командой `horizon-mixins apply` к отдельной копии
Horizon, затем выполните `cargo check -p horizon-client` в полученной папке.
Параметры `--workspace`, `--mods`, `--out` должны быть абсолютными путями;
выходная папка не должна находиться внутри исходной.

Проверка компиляции и шейдеров не заменяет запуск в игре: производительность,
визуальные эффекты на конкретном GPU и совместимость с другими модами требуют
отдельной игровой проверки.

- Тесты нативного движка в release: **137 passed, 0 failed, 35 ignored**.
  Отключённые автором генераторы данных и специальные профилировочные тесты не запускались.
- Все **15** встроенных шейдерных проходов прошли проверку Naga 30.0.1.
- Упаковка: проверены содержимое ZIP, отсутствие файлов компилятора и повторяемость SHA-256.

Запуск клиента в игровом мире, графика на конкретной видеокарте и сочетания с
другими модами в этой проверке не тестировались. `cargo check` проверяет типы
и компиляцию исходников, но не собирает готовый игровой executable; его собирает лаунчер.
